# Minto Pyramid

Use to organize a message around its answer. Supply the audience, question, known
facts, and any length or format constraint. This method organizes evidence; it
does not supply missing evidence or validate a decision by itself.

## Procedure

1. Identify the audience's main question and the supported answer. If undecided,
   lead with the decision needed or the evidence gap instead of inventing a verdict.
2. Group supporting reasons logically, avoiding duplication or unrelated claims.
3. Place evidence under the reason it supports. Preserve qualifications that could
   change the answer. Use as many groups as the content needs, not exactly three.
4. Include situation, complication, and question only where context is needed;
   do not bury the answer under a ceremonial introduction.
5. Edit to the requested length and end with a next action when appropriate.

Output the revised message, not an essay describing the pyramid. Stop when each
detail supports the main point and the audience can identify the needed action.

## Example and boundary

Notes: "Export tests pass. Import compatibility is untested. Deadline Friday."
For a readiness update: "Release readiness remains unconfirmed because import
compatibility is untested. Export tests pass. Check imports before Friday's decision."
Do not rewrite this as "Ready to release" or create two extra arguments to fill a template.
